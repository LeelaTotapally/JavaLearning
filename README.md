# Addition Program in Java

This is a simple Java program that takes two integer inputs from the user, adds them, and prints the result. The program is designed to illustrate basic Java functionality such as reading user input, performing arithmetic operations, and displaying output.

## Features
- Accepts two integer inputs from the user.
- Performs addition of the two integers.
- Displays the result in the console.

## Prerequisites
- Java Development Kit (JDK) installed on your machine.

## How to Run

1. Clone the repository or save the `AdditionProgram.java` file.
2. Open a terminal and navigate to the `src` directory containing the `AdditionProgram.java` file.
3. Compile the Java program with the following command:
   
   javac AdditionProgram.java
   
4. Run the compiled program using:
   
   java AdditionProgram
   
5. Follow the prompts in the console to input two integers, and the program will display the sum.

## Example Usage

Welcome to the Addition Program!
Enter the first number: 10
Enter the second number: 20
The sum of 10 and 20 is: 30


## Testing
You can test the program by running it multiple times and providing different sets of integer inputs to verify the correctness of the addition function.
